# 단체 식당 검색 v4

## 핵심 변경
이제 거리를 코드에 직접 저장하는 구조에서 **좌표 기반 자동 계산 구조**로 전환했습니다.

### locations.json
기준 장소는 다음 정보만 추가하면 됩니다.

```json
{
  "id": "new_place",
  "name": "새 기준 장소",
  "address": "주소",
  "latitude": 37.1234,
  "longitude": 127.1234
}
```

### restaurants.json
식당 좌표가 검증되면 아래처럼 넣습니다.

```json
{
  "name": "식당 이름",
  "latitude": 37.1234,
  "longitude": 127.1234
}
```

웹페이지는 Haversine 공식으로 기준 장소와 식당 사이의 직선거리를 자동 계산합니다.

## 현재 과도기 동작
v3 식당 30곳은 기존 거리값을 `legacy_distance_km`로 보존했습니다.
정확한 좌표가 입력된 식당은 자동 계산값을 우선 사용하고,
좌표가 아직 검증되지 않은 식당은 기존 조사값을 임시 사용합니다.

화면의 `거리 기준` 열에서:
- `좌표 자동계산` = 위/경도로 계산
- `기존 조사값` = 아직 좌표 검증 전

## 왜 이렇게 구성했나
검색에서 주소를 확인할 수 있어도 위도/경도 숫자가 직접 제공되지 않는 식당이 많습니다.
검증하지 않은 좌표를 임의로 넣으면 반경 필터가 틀릴 수 있으므로 좌표값을 추측하지 않았습니다.
